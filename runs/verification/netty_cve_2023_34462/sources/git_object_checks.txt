  The 4.1.94 fix keeps MAX_CLIENT_HELLO_LENGTH (0xFFFFFF, ~16MB) as the DEFAULT maximum,

  classifies the issue as fixed in 4.1.94 because the limit can now be configured. The
  dossier must not claim that the default allocation was reduced.
