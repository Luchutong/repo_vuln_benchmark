        final StaplerRequest request = Stapler.getCurrentRequest();

  There is no @POST (or @RequirePOST) annotation on the method; the class uses
  @POST elsewhere (for example 4051, 4104, 4295), so the absence here is a real
  omission rather than a version where the annotation is unavailable.
  Request is a GET with a query parameter, so a cross-site <img>/link can trigger it.
  PaneStatusProperties (blob 29a46034) holds a Set<String> collapsed; its
  toggleCollapsed at 26-34 adds or removes the supplied paneId, and save() at 37-39
  calls user.save(), so an arbitrary paneId string is persisted in the victim's user
  profile (or the session fallback at 61-83 when no user is logged in).
  pane.jelly at 2.441 (blob e7c4a04a) line 62 renders the trigger as a plain link:
    <a class="collapse" href="${rootURL}/toggleCollapse?paneId=${attrs.id}"
