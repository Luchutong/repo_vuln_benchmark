  `_os_alt_seps` (lines 12-14) holds os.sep / os.path.altsep except "/", i.e.
  the backslash on Windows. On Windows with Python < 3.11, ntpath.isabs()
  returns False for a UNC path such as //server/share (the advisory's own
  wording), and posixpath.normpath leaves "//b/c" unchanged, so a pathname
  beginning with "//" (or a plain "/...") passes every predicate and is joined
  onto the base directory. os.path.join / posixpath.join then produce a path
  rooted outside the directory, so a caller that trusts safe_join serves or
  opens data outside its base directory. The missing predicate is exactly
  `filename.startswith("/")`; the other three checks already exist.
