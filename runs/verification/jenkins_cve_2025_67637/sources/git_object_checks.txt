  The token is a plain String both at rest and in the XStream representation used for
  job config.xml, so the serialized job configuration contains the build
  authorization token in clear text. Jenkins' config.xml redaction (from 2.500) only
  handles Secret values, so a user with Item/Extended Read sees this string
  unmasked, and it is also readable in clear text on the controller file system.
