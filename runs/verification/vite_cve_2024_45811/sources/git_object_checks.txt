Vulnerable code at the snapshot:
  packages/vite/src/node/server/middlewares/transform.ts lines 137-142 open the
  import/JS request branch (isJSRequest/isImportRequest/isCSSRequest/isHTMLProxy)
  without an ensureServingAccess call. A `?import&raw` URL enters this branch,
  removeImportQuery (line 144) and unwrapId (line 147) leave `/@fs/<path>?raw`,
  and transformRequest (line 172) runs the asset plugin's load hook, which at
  lines 189-196 of asset.ts matches rawRE and returns `await fsp.readFile(file,
  'utf-8')` (line 194) for the resolved file without consulting
  isFileServingAllowed. transformRequest's own isFileServingAllowed check
  (transformRequest.ts line 212) only guards its fallback fs branch, which is
  not reached because the asset plugin returns code for the raw query. The
  serveRawFsMiddleware check in static.ts (lines 181-191) is bypassed because
  the request is answered by the transform middleware first. Extensionless
  targets also reach this branch with a plain `?raw` through isJSRequest.
