  `template` comes straight from the URL (see the route below) and is passed to
  the pathlib `/` operator without any sanitation. If it is an absolute path
  such as "/etc/passwd", pathlib discards `directory` and yields the absolute
  path; if it is "../passwd" the joined path escapes the template directory.
  `template_file.exists()` then tells the staff user whether that file exists,
  and `template_contents` is placed in the context. The stock
  template_detail.html only renders `template.file` and the exists flag, but
  the advisory notes that a customized admindocs template that also renders
  `template.contents` exposes the file contents as well.

  The `<path:...>` converter matches any non-empty string including slashes and
  a leading slash, so `/admin/doc/templates//etc/passwd/` passes
  template="/etc/passwd". BaseAdminDocsView.dispatch is decorated with
  staff_member_required (line 33), so a staff account is required; the
  admindocs app is optional and only present when the project installs
  django.contrib.admindocs and includes its urls.
