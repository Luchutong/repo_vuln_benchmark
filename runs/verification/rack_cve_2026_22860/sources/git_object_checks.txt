  Utils.valid_path? (lib/rack/utils.rb:608-610) only rejects invalid encodings
  and NUL bytes, so ".." passes check_bad_request. File.join(@root, "/../root_test/")
  keeps the ".." segment; File.expand_path then resolves it to a sibling
  directory (e.g. "/tmp/x/root_test"), which still starts_with?("/tmp/x/root"),
  so check_forbidden returns nil and list_path stats the unnormalised path and
  serves a directory listing of the sibling.
