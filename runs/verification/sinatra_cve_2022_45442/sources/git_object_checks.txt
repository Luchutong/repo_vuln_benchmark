Vulnerable code at the snapshot (v3.0.3, blob d7e2d65):
  lib/sinatra/base.rb:401-410  def attachment(filename = nil, disposition = :attachment)
  ... 402  response['Content-Disposition'] = disposition.to_s.dup
  ... 403  return unless filename
  ... 405  params = format('; filename="%s"', File.basename(filename))
  ... 406  response['Content-Disposition'] << params
  ... 408  content_type(ext) unless response['Content-Type'] || ext.empty?
  File.basename only removes directory components; it does not remove or encode
  `"`, CR or LF. The result is interpolated directly between the quotes of the
  Content-Disposition filename parameter, so a filename containing a quote and a
  CRLF sequence closes the quoted string and appends arbitrary header
  parameters (the fix's own regression test uses
  "test.xml\";\r\next=.txt"). The same helper is used by send_file when a
  :filename option is supplied.
