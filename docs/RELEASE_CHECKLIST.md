- [ ] 当前 `snapshot_candidate_triage` 覆盖全部现有候选；排除决策必须保留源证据，尚有 `possible_affected`/`unknown` 时不得声称完整快照已知正样本闭环。

- [ ] 输出按仓库宏平均 Known Recall、已知漏洞定位/严重程度分指标，未匹配项须独立裁决；禁止把未匹配直接判误报。
- [ ] 每调用实际 token/模型/费用和剩余预算已可审计；网关已实现预估/累计限额或明确声明只有离线汇总而无法阻断。
- [ ] Schema 严格验证 0 errors，完整披露尚未裁决的版本相关漏洞、历史未处理数量及有限覆盖性质。
