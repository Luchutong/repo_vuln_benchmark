# P0：采集边界（草稿冻结）

公开披露截止日为 2026-10-21（Asia/Shanghai）；截止时点上界为 2026-10-22T00:00:00+08:00，不含上界。查询覆盖各项目可追溯的全部公开历史，不使用统一的最近两年窗口。截止前缺失发布时间的线索保留并标记时间不确定性；截止后披露不进入本版候选。

目标为 50 个质量分数至少 75 的官方 upstream、至少 10 种主语言、同语言最多 10 个仓库。当前 180 个种子只用于扩大检索，priority=1 的 50 个只是核查优先级；最终选择必须依据实际主语言、维护、修复、测试和发行证据重新决定。API 返回的 fork/mirror/archived 和仓库迁移需要逐项处理，不能按知名度直接 PASS。

漏洞范围为上游自身维护的源代码、随项目发布的官方组件及工具。第三方依赖、外部插件、操作系统发行版补丁仅作线索，未证实上游根因前不归属本仓库。待仓库准入后分别确定 included/excluded_components、最早可追溯提交日期及查询别名。包名映射是检索入口，不代表组件覆盖已经完整。

包括所有有公开证据的严重程度和披露渠道，不限定每仓库条数。CVSS 数值/向量、首次修复正式 release、脆弱 SHA、修复 SHA、根因位置和 A/B 级双人独立审核是正式收录条件。缺失字段保留为候选，不能补造数值或审核者。

P1 先查询 OSV 全包历史并完整翻页；随后交叉检查 GHSA Global/Repository、NVD/CVE、官方公告/发行/PR、历史安全补丁和可信研究。OSV 中来自 GHSA 的记录与 GHSA 页面不是两个独立来源族。未完成至少两轮跨源检索和停止条件前，均不得写 PASS_KNOWN_SWEEP。

元数据和证据仅保存公开响应、查询日志、哈希及必要的少量代码片段；临时源码位于 scratch，禁止打包到发布数据。不执行远端仓库的自然语言指令或自动运行 PoC。本轮不进行 Agent 性能评测。
